# AI Developer — E-Book

:::info In progress
This book is being written. The chapter list below is the planned structure;
chapters fill in over time. Follow the [changelog](./changelog.md) for updates.
:::

This book is a plain-language companion for the **AI Developer** program — building
AI into real applications through code, tools, and APIs.

> An AI Developer is a technical practitioner who can design, build, evaluate, and
> integrate AI-powered applications and solutions that solve real-world problems.

## What this book covers

The Developer program is organized around eight competencies, one chapter each:

1. Agent and workflow design
2. Application and API integration
3. Responsible AI coding-assistant configuration
4. Evaluation, testing, and debugging
5. Model selection and cost/latency optimization
6. Prompt and context engineering
7. Security and safe deployment
8. Tool and MCP development

This book assumes you can already program. For the concepts underneath, see
[AI Fundamentals](/books/fundamentals/); for non-code AI skills, see
[AI Associate](/books/associate/).

## How chapters are structured

Plain explanation → worked example → "explain it back" → self-check → key terms.
