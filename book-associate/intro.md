:::info In progress

:::

This book is a plain-language companion for the **AI Associate** program — the
everyday professional skills for using AI well in real work.

> An AI Associate is a professional who can independently apply AI to everyday
> work, evaluate its results, use it responsibly, and recognize when human or
> technical expertise is required.

## What this book covers

The Associate program is organized around seven competencies, one chapter each:

1. Prompting and task execution
2. Output evaluation and validation
3. Product and model selection
4. Workflow integration and solution design
5. Configuration and knowledge management
6. Governance, risk, and responsible use
7. Troubleshooting and optimization

No coding is required. If you want the conceptual groundwork first, read
[AI Fundamentals](/books/fundamentals/).

## How chapters are structured

Plain explanation → worked example → "explain it back" → self-check → key terms.
